MEU FINANCEIRO — Versão gratuita 0.4

1. Abra index.html para testar no computador (armazenamento local).
2. Para usar como aplicativo instalável no iPhone, publique TODOS os arquivos em hospedagem estática HTTPS (ex.: GitHub Pages, plano gratuito), abra o endereço no Safari e use Compartilhar > Adicionar à Tela de Início. O arquivo HTML aberto localmente não instala PWA.
3. Cadastro: digite "Uber 20 crédito" no campo Registro instantâneo e toque Registrar.
4. Voz: toque Falar e permita acesso ao microfone, se houver suporte Web Speech API. Reconhecimento de voz não é garantido/offline e pode depender de serviços de terceiros do navegador. Alternativa no iPhone: toque no campo de texto e utilize o microfone do teclado.
5. Dados ficam apenas no dispositivo/navegador. Backup CSV regularmente; importar CSV para restaurar. Não existe sincronização automática Supabase nesta versão.
6. Nenhuma receita ou informação de salário é registrada/exibida.
7. Sem cobrança de serviços do aplicativo; acesso à internet e eventual hospedagem têm seus próprios termos.
